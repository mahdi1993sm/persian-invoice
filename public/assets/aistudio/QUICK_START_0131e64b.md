# 🚀 شروع سریع - Quick Start Guide

## 🎯 در ۵ دقیقه شروع کنید!

این راهنما به شما کمک می‌کند در **کمتر از ۵ دقیقه** پروژه را اجرا کنید و با قابلیت‌های اصلی آن آشنا شوید.

---

## 📋 پیش‌نیازها

قبل از شروع، مطمئن شوید که موارد زیر را دارید:

- ✅ **Node.js** نسخه ۱۸ یا بالاتر
- ✅ **npm** یا **yarn** یا **pnpm**
- ✅ یک **مرورگر مدرن** (Chrome, Firefox, Edge, Safari)
- ✅ یک **ویرایشگر کد** (VS Code پیشنهاد می‌شود)

### بررسی Node.js

```bash
node --version
# باید v18.0.0 یا بالاتر باشد

npm --version
# باید ۹.۰.۰ یا بالاتر باشد
```

---

## 🎬 شروع در ۳ مرحله

### مرحله ۱: نصب وابستگی‌ها (۱ دقیقه)

```bash
# در پوشه پروژه
npm install
```

**چه اتفاقی می‌افتد؟**
- تمام پکیج‌های مورد نیاز دانلود می‌شوند
- node_modules ایجاد می‌شود
- وابستگی‌ها نصب می‌شوند

**زمان تقریبی**: ۱-۲ دقیقه (بسته به سرعت اینترنت)

---

### مرحله ۲: اجرای پروژه (۱۰ ثانیه)

```bash
npm run dev
```

**چه اتفاقی می‌افتد؟**
- سرور توسعه Vite شروع می‌شود
- پروژه در http://localhost:5173 اجرا می‌شود
- Hot Module Replacement فعال می‌شود

**خروجی مورد انتظار**:
```
  VITE v6.0.3  ready in 500 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

---

### مرحله ۳: باز کردن در مرورگر (۵ ثانیه)

مرورگر را باز کنید و به آدرس زیر بروید:

```
http://localhost:5173
```

**تبریک! 🎉 پروژه شما در حال اجراست!**

---

## 🎯 اولین استفاده

### ۱. تنظیم اطلاعات فروشنده

1. از منوی کناری، روی **"اطلاعات فروشنده"** کلیک کنید
2. اطلاعات فروشگاه/شرکت خود را وارد کنید:
   - نام فروشگاه
   - تلفن
   - آدرس
   - و غیره
3. (اختیاری) امضا و مهر خود را آپلود کنید
4. روی **"ذخیره اطلاعات"** کلیک کنید

### ۲. افزودن مشتری

1. از منوی کناری، روی **"مشتریان"** کلیک کنید
2. روی دکمه **"مشتری جدید"** کلیک کنید
3. اطلاعات مشتری را وارد کنید:
   - نام (اجباری)
   - تلفن
   - موبایل
   - آدرس
   - و غیره
4. روی **"ثبت مشتری"** کلیک کنید

### ۳. افزودن کالا

1. از منوی کناری، روی **"کالاها"** کلیک کنید
2. روی دکمه **"کالای جدید"** کلیک کنید
3. اطلاعات کالا را وارد کنید:
   - نام (اجباری)
   - کد
   - واحد
   - قیمت (اجباری)
   - دسته‌بندی
4. روی **"ثبت کالا"** کلیک کنید

### ۴. صدور فاکتور

1. از منوی کناری، روی **"صدور فاکتور"** کلیک کنید
2. **انتخاب مشتری**:
   - روی دکمه "انتخاب مشتری" کلیک کنید
   - مشتری را از لیست انتخاب کنید
   - یا روی "مشتری جدید" کلیک کنید
3. **افزودن اقلام**:
   - روی "انتخاب کالا" کلیک کنید
   - کالا را انتخاب کنید
   - تعداد و قیمت را تنظیم کنید
4. **تنظیمات مالی**:
   - تخفیف (درصد)
   - مالیات (درصد)
   - مبلغ پرداختی
5. **نحوه تسویه**:
   - نقدی (با انتخاب روش واریز)
   - نسیه
   - چک (با اطلاعات چک صیادی)
6. روی **"ثبت و صدور فاکتور"** کلیک کنید

### ۵. مشاهده و چاپ فاکتور

1. پس از ثبت، فاکتور به صورت خودکار باز می‌شود
2. از دکمه‌های بالا استفاده کنید:
   - **پرینت**: چاپ فاکتور
   - **PDF**: دانلود فایل PDF
   - **اشتراک**: اشتراک‌گذاری در پیام‌رسان‌ها

## ⌨️ میانبرهای کیبورد

برای سرعت بیشتر، از این میانبرها استفاده کنید:

| کلید | عملکرد |
|------|--------|
| `Ctrl + D` | تغییر حالت تاریک/روشن |
| `Ctrl + N` | فاکتور جدید |
| `Ctrl + L` | لیست فاکتورها |
| `Ctrl + ,` | تنظیمات |

## 🎨 شخصی‌سازی

### تغییر رنگ تم

1. روی آیکون ⚙️ (تنظیمات) در هدر کلیک کنید
2. در تب **"عمومی"**، بخش **"رنگ اصلی برنامه"**
3. یکی از ۸ رنگ را انتخاب کنید
4. تغییرات بلافاصله اعمال می‌شوند

### تغییر حالت تاریک

1. روی آیکون 🌙/☀️ در هدر کلیک کنید
2. یا از `Ctrl + D` استفاده کنید

### تغییر واحد پول

1. تنظیمات > عمومی > واحد پول
2. انتخاب: تومان / ریال / سفارشی
3. ذخیره

---

## 💾 بکاپ گیری

### خروجی JSON

1. تنظیمات > داده‌ها
2. روی **"دانلود JSON"** کلیک کنید
3. فایل بکاپ دانلود می‌شود

### خروجی اکسل

1. تنظیمات > داده‌ها
2. روی **"دانلود اکسل"** کلیک کنید
3. فایل اکسل با ۴ شیت دانلود می‌شود

### ورودی داده

1. تنظیمات > داده‌ها
2. روی **"انتخاب فایل"** کلیک کنید
3. فایل JSON یا Excel را انتخاب کنید
4. داده‌ها به صورت خودکار وارد می‌شوند

## 🐛 رفع مشکلات رایج

### مشکل: پروژه اجرا نمی‌شود

**راه حل**:
```bash
# پاک کردن node_modules
rm -rf node_modules

# نصب مجدد
npm install

# اجرا
npm run dev
```

### مشکل: خطای نسخه Node.js

**راه حل**:
```bash
# بررسی نسخه
node --version

# اگر قدیمی است، از nvm استفاده کنید
nvm install 18
nvm use 18
```

### مشکل: پورت 5173 اشغال است

**راه حل**:
```bash
# استفاده از پورت دیگر
npm run dev -- --port 3000

# یا پیدا کردن و بستن پورت اشغال شده
# Windows:
netstat -ano | findstr :5173
taskkill /PID <PID> /F

# Linux/Mac:
lsof -ti:5173 | xargs kill -9
```

### مشکل: داده‌ها از بین رفته‌اند

**راه حل**:
- اگر بکاپ دارید: تنظیمات > داده‌ها > ورودی
- اگر بکاپ ندارید: متأسفانه داده‌ها قابل بازیابی نیستند
- **پیشنهاد**: به صورت دوره‌ای بکاپ بگیرید

## 🎓 نکات مهم

### برای کاربران جدید

1. **ابتدا اطلاعات فروشنده را وارد کنید** - این اطلاعات در تمام فاکتورها نمایش داده می‌شود
2. **مشتریان و کالاها را ثبت کنید** - قبل از صدور فاکتور
3. **به صورت دوره‌ای بکاپ بگیرید** - تنظیمات > داده‌ها
4. **از میانبرهای کیبورد استفاده کنید** - سرعت بیشتر

### برای توسعه‌دهندگان

1. **کد را بخوانید** - کامنت‌ها و TypeScript definitions
2. **از Hot Reload استفاده کنید** - تغییرات بلافاصله اعمال می‌شوند
3. **Console را بررسی کنید** - خطاها و warning ها
4. **DevTools را استفاده کنید** - React DevTools, Redux DevTools

### برای بهینه‌سازی

1. **از بکاپ خودکار استفاده کنید** - تنظیمات > داده‌ها
2. **داده‌های قدیمی را حذف کنید** - مدیریت داده‌ها
3. **از فیلترها استفاده کنید** - جستجوی سریع‌تر
4. **از میانبرها استفاده کنید** - سرعت بیشتر
