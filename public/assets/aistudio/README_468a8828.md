# 🏢 سیستم صدور فاکتور فروش - نمای کلی پروژه

## 📖 درباره پروژه

یک **اپلیکیشن تحت وب کامل** برای مدیریت فاکتورهای فروش با **React + TypeScript + Tailwind CSS**. تمام داده‌ها در مرورگر ذخیره می‌شوند و نیازی به سرور ندارند.

## 🔧 ویژگی‌های فنی

### State Management
```typescript
// Zustand Store با persist
const useStore = create<AppState>()(
  persist(
    (set, get) => ({
      // State
      customers: [],
      products: [],
      invoices: [],

      // Actions
      addCustomer: (customer) => set((state) => ({
        customers: [...state.customers, customer]
      })),

      // Derived
      getCurrencyLabel: () => { /* ... */ }
    }),
    { name: 'invoice-app-storage' }
  )
);
```

// استفاده از Portal برای جلوگیری از تداخل

## 🎯 گردش کار (Workflow)

### صدور فاکتور
```
۱. انتخاب مشتری (جستجو یا ثبت جدید)
   ↓
۲. افزودن اقلام (انتخاب یا ثبت کالای جدید)
   ↓
۳. تنظیم تخفیف و مالیات
   ↓
۴. انتخاب نحوه تسویه (نقدی/نسیه/چک)
   ↓
۵. ثبت فاکتور
   ↓
۶. مشاهده/چاپ/PDF/اشتراک
```

### مدیریت داده‌ها
```
۱. ورود به تنظیمات > داده‌ها
   ↓
۲. انتخاب نوع خروجی (JSON/Excel)
   ↓
۳. دانلود فایل
   ↓
۴. یا بارگذاری فایل برای ورود داده
```
