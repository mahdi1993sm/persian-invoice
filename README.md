# 📄 نرم‌افزار هوشمند صدور و مدیریت فاکتور فروش (Persian Invoice)

اپلیکیشن حرفه‌ای و مدرن اندروید برای صدور، چاپ و اشتراک‌گذاری فاکتورهای رسمی و غیررسمی با پشتیبانی کامل از زبان فارسی، تقویم جلالی، و کارکرد **۱۰۰٪ آفلاین**.

> 🌐 **صفحه وب و مستندات پروژه:** فایل [`index.html`](./index.html) جهت پیش‌نمایش، معرفی ساختار کدها و لندینگ پیج در ریشه مخزن قرار دارد.

---

## 🌟 قابلیت‌ها و ویژگی‌های کلیدی

- **📄 صدور PDF استاندارد چندصفحه‌ای:**
  - موتور هوشمند صفحه‌بندی خودکار با سربرگ تکرارشونده در تمام صفحات
  - درج شماره صفحه، تاریخ جلالی و جایگاه رسمی مهر و امضای طرفین
  - پیش‌نمایش سریع قبل از چاپ و خروجی مستقیم در پوشه دانلودها
- **📦 مدیریت پیشرفته کالاها و انبار با ویرایش گروهی:**
  - ثبت و ویرایش کالاها با واحد سنجش و قیمت فروش
  - فیلتر دسته‌بندی و جستجوی لحظه‌ای
  - ابزار ویرایش گروهی (Batch Operations): افزایش یا کاهش درصدی/مبلغی قیمت‌ها، تغییر دسته و حذف گروهی
- **👥 مدیریت طرف‌های حساب و مشتریان:**
  - اعتبارسنجی خودکار فیلدهای هویتی: کد ملی (۱۰ رقم)، موبایل (۱۱ رقم با ۰۹)، کد پستی (۱۰ رقم)
  - کادر قرمز و متن راهنما برای فیلدهای اجباری جامانده با اسکرول خودکار
- **💳 شرایط مالی و تسویه فاکتور:**
  - ثبت پرداخت‌های نقدی، دستگاه کارتخوان (POS)، کارت‌به‌کارت، پایا، ساتنا، چک و نسیه
  - محاسبه آنی جمع کل، تخفیف، مالیات و مانده بدهی
- **📊 داشبورد آماری و گزارش‌گیری:**
  - نمودار ماهانه فروش سال جاری بر اساس تقویم شمسی
  - کارت‌های آماری کلیک‌پذیر با هدایت مستقیم به فیلترهای فاکتور (تسویه‌شده، نسیه، مشتریان)
- **🍔 منوی همبرگری و ناوبری روان:**
  - دسترسی آسان به تمامی بخش‌ها (فاکتورها، کالاها، مشتریان، حساب‌های بانکی، مشخصات فروشنده، تنظیمات و درباره ما)
- **🔒 آفلاین و کاملاً امن (Offline-First):**
  - تمامی داده‌ها مستقیماً درون پایگاه داده محلی Room SQLite روی گوشی کاربر ذخیره می‌شوند.
  - بدون نیاز به اینترنت و بدون تاخیر.

## 🛠 معماری فنی و فناوری‌ها

- **زبان برنامه‌نویسی:** Kotlin
- **رابط کاربری:** Jetpack Compose (Material Design 3)
- **معماری:** MVVM + Clean Architecture با Kotlin Coroutines و StateFlow
- **پایگاه داده محلی:** Android Room Database (SQLite)
- **رندر گرافیکی و PDF:** Android Native Canvas & PdfDocument
- **تقویم و فرمت اعداد:** موتور اختصاصی تقویم جلالی و تبدیل ارقام به فارسی
- **زیرساخت ابری (اختیاری):** Firebase Firestore & Google Auth

## 🚀 نحوه اجرا و ساخت پروژه

1. پروژه را در **Android Studio** باز کنید (نسخه Hedgehog یا جدیدتر توصیه می‌شود).
2. اجازه دهید فرایند Gradle Sync تکمیل شود.
3. جهت ساخت APK به صورت خط فرمان:
   ```bash
   gradle :app:assembleDebug
   ```
   یا خروجی نهایی Release:
   ```bash
   gradle :app:assembleRelease
   ```
4. فایل نصب شده را روی دستگاه اندرویدی (اندروید نسخه ۷.۰ به بالا) اجرا کنید.
